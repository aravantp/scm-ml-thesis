# Machine Learning in Supply Chain Management Systems
## Master Thesis — EKPA, 2026-2027

### Title
"The Impact of Machine Learning Algorithms on Supply Chain 
Management Systems: Digital Twins, Generative AI and Blockchain"

### Description
This repository contains the code, analysis and results for 
my master thesis at the University of Athens (EKPA), 
Department of Business Administration, Analytics and 
Information Systems.

### Dataset
DataCo Smart Supply Chain Dataset
- Source: Mendeley Data
- DOI: 10.17632/8gx2fvg2k6.5
- Records: 180,519
- Variables: 53

### Structure
- notebooks/ : Jupyter notebooks for each analysis step
- models/    : Python scripts for ML models
- app/       : Gradio web application
- data/      : Datasets (raw and processed)
- thesis/    : Figures and outputs for the thesis

### Technologies
- Python, Scikit-learn, TensorFlow/Keras
- MLflow for experiment tracking
- Gradio for web application
- GitHub for version control

### Analysis Pipeline
1. EDA & Descriptive Statistics
2. Data Preprocessing
3. Classification (Logistic Regression, Random Forest, SVM, Neural Network)
4. Regression (Linear Regression, Random Forest Regressor)
5. Clustering (K-Means, DBSCAN)
6. Overfitting Analysis & External Validation
7. Stress Testing (Adversarial Testing)
8. Case Study (Digital Twin + GenAI + Blockchain simulation)
